# 1️⃣ Engineering Mathematics-I (BAS-103)

### Unit 1: Matrices
| Topic | Details |
|-------|---------|
| Types of Matrices | Symmetric, Skew-Symmetric, Hermitian, Skew-Hermitian, Unitary, Orthogonal |
| Elementary Transformations | Row & Column operations |
| Rank of a Matrix | Echelon form, Normal form |
| Inverse of a Matrix | Using Row Operations (Gauss-Jordan) ← *You are here* |
| System of Linear Equations | Consistency, Gauss elimination, Homogeneous & Non-homogeneous |
| Eigenvalues & Eigenvectors | Characteristic equation, properties |
| Cayley-Hamilton Theorem | Verification and applications |

### Unit 2: Differential Calculus — I
| Topic | Details |
|-------|---------|
| Successive Differentiation | nth order derivatives of standard functions |
| Leibnitz's Theorem | nth derivative of product of two functions |
| Curve Tracing | Cartesian & Polar curves |
| Partial Derivatives | First & higher order |
| Euler's Theorem | For homogeneous functions |
| Total Derivative | Change of variables |

### Unit 3: Differential Calculus — II
| Topic | Details |
|-------|---------|
| Taylor's & Maclaurin's Theorem | Expansion of f(x) and f(x,y) |
| Maxima & Minima | Functions of several variables |
| Lagrange's Multipliers | Constrained optimization |
| Jacobians | Definition, properties, applications |
| Approximation of Errors | Using partial derivatives |

### Unit 4: Multiple Integration
| Topic | Details |
|-------|---------|
| Double Integrals | Evaluation, change of order of integration |
| Triple Integrals | Cartesian, Cylindrical & Spherical coordinates |
| Change of Variables | Polar, Cylindrical, Spherical |
| Beta & Gamma Functions | Properties, relation between them, Γ(1/2) = √π |
| Dirichlet's Integral | Applications to area & volume |

### Unit 5: Vector Calculus
| Topic | Details |
|-------|---------|
| Gradient (∇f) | Directional derivative, normal to surfaces |
| Divergence (∇·F) | Solenoidal vectors |
| Curl (∇×F) | Irrotational vectors |
| Line, Surface & Volume Integrals | Evaluation techniques |
| Green's Theorem | Line integral ↔ Double integral |
| Stokes' Theorem | Line integral ↔ Surface integral |
| Gauss Divergence Theorem | Surface integral ↔ Volume integral |

> [!TIP]
> **Best Book:** B.S. Grewal — *Higher Engineering Mathematics*

## 🎯 Scoring Strategy

| Subject | Strategy |
|---------|----------|
| Maths (BAS-103) | Practice numericals daily — no shortcuts |
| Programming (BCS-101) | Write code by hand, practice flowcharts |
| Soft Skills (BAS-105) | Easy marks — write neatly in points |
| Chemistry (BAS-102) | Focus on numericals (water, electrochemistry) + diagrams |
| Electronics (BEC-101) | Learn circuit diagrams + practice K-Maps |
| Environment (BAS-104) | Easiest — memorize keywords, solve PYQs |
| Mechanical (BME-101) | Draw diagrams (FBD, engines, cycles) + numericals |

> [!IMPORTANT]
> **Always solve AKTU Previous Year Question Papers (PYQs)** — many questions repeat directly. Check sites like **aktupyq.com** and **studentsenior.com** for free PYQs.
